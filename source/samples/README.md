# Public Toy Samples

This folder contains small, original toy records for smoke tests and public
documentation. They are not copied from Safety-Prompts, JailBench, JailJudge,
MultiJail, or the private source-data archive.

The full research source files are intentionally excluded from the public
repository. Use `scripts/prepare_source_data.py` with an access-controlled local
export when running experiments that require the complete source corpus.
