# Public Toy Samples

This folder contains small, original toy records for smoke tests and
documentation. They are not copied from Safety-Prompts, JailBench, JailJudge,
MultiJail, or a local source-data export.

The full research source files are intentionally excluded from this repository.
Use `scripts/prepare_source_data.py` with an access-controlled local
export when running experiments that require the complete source corpus.
